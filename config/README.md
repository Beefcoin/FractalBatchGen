# Generation Configurations

JSON files in this directory define the agglomerates generated by `batch_generate.py`.

## Basic structure

```json
{
    "output_directory": "generated/example",
    "liggghts": {
        "enabled": true,
        "density": 2.0
    },
    "algorithms": {
        "FracVAL": {
            "enabled": true,
            "script": "FracVAL.py",
            "generates": [
                {
                    "Np": [10, 50, 100],
                    "Df": 2.4,
                    "kf": 1.3,
                    "Dp_geo": 0.97,
                    "Dp_gsd": 1.0,
                    "tol_ov": 1e-6,
                    "random_seed": [1029, 1030]
                },
                {
                    "Np": [10, 50, 100],
                    "Df": 1.5,
                    "kf": 1.5,
                    "Dp_geo": 0.97,
                    "Dp_gsd": 1.0,
                    "tol_ov": 1e-6,
                    "random_seed": [1029, 1030]
                }
            ]
        }
    }
}
```

## `generates`

Each object inside `generates` is an independent generation set.

Arrays inside one set are combined as a Cartesian product. Scalar values stay constant.

For example:

```json
{
    "Np": [10, 50, 100],
    "Df": 2.4,
    "kf": 1.3,
    "random_seed": [1029, 1030]
}
```

produces 3 × 2 = 6 runs.

Use multiple generation sets when specific parameter combinations should be kept together. For example, separate sets for `Df=2.4, kf=1.3` and `Df=1.5, kf=1.5` prevent unwanted cross-combinations.

## Algorithm parameters

### FracVAL

- `Np` — number of primary particles
- `Df` — fractal dimension
- `kf` — fractal prefactor
- `Dp_geo` — geometric mean particle diameter
- `Dp_gsd` — geometric standard deviation
- `tol_ov` — overlap tolerance
- `random_seed` — random seed

### Skorupski

- `N_target` — number of primary particles
- `Df` — fractal dimension
- `kf` — fractal prefactor
- `particle_radius` — primary particle radius
- `random_seed` — random seed
- `max_try` — maximum placement attempts
- `plot-scaling` — enable scaling plot

### Urbassek

- `N_target` — number of primary particles
- `particle_radius` — primary particle radius
- `r_sigma_mult` — local environment radius multiplier
- `random_seed` — random seed
- `max_try` — maximum placement attempts

## LIGGGHTS output

```json
"liggghts": {
    "enabled": true,
    "density": 2.0
}
```

When enabled, `.sys` files are written to the `sys/` subdirectory of the corresponding algorithm output directory.

## Running

```bash
./generate.sh config/genTest_skorupski.json
./generate.sh config/genTest_urbassek.json
./generate.sh config/genTest_fracval.json
```
